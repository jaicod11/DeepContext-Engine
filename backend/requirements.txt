# ── Reranker — DELIBERATELY NOT INSTALLED HERE ────────────────
# sentence-transformers + torch live in requirements-reranker.txt.
#
# They are excluded by default because installing them makes torch load at
# STARTUP even when RERANKER_ENABLED=False: sentence-transformers pulls in
# `transformers`, and langchain_core.language_models.base imports it during
# the normal app import chain (main -> query route -> rag_chain ->
# prompt_templates -> langchain_core). Verified with an import tracer.
#
# So on a 512MB instance the flag alone is NOT enough — the packages must be
# absent too. Installing them adds ~450MB to the environment (1.1G vs 659M
# measured) and enough resident memory to get OOM-killed on free tiers.
#
# To enable reranking on an instance with headroom (>=2GB):
#     pip install -r requirements.txt -r requirements-reranker.txt
#
# With them absent and RERANKER_ENABLED left at its default of True, queries
# fail with a clear RuntimeError from reranker_service._load_model() telling
# you to install sentence-transformers — set RERANKER_ENABLED=False to avoid
# it. See DEPLOYMENT.md.
